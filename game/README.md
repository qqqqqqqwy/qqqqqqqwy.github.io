# Parry assets

Original game-inspired assets for qiwenyu's homepage; no extracted Sekiro assets.

- warning.wav, parry.wav, death.wav: original deterministic sound synthesis by site/scripts/prepare-media.py. CC0-1.0.
- peril.png, death.png: pixel-rendered glyphs from Ma Shan Zheng, under the SIL Open Font License. See MaShanZheng-OFL.txt.
- Typeface source: https://github.com/google/fonts/tree/main/ofl/mashanzheng

Regenerate: python site/scripts/prepare-media.py (requires Pillow, imageio-ffmpeg; optionally set FFMPEG and BRUSH_FONT).
